## 🖥️ What this app does

Polymarket-Market-Maker-Bot helps you place market-making orders on Polymarket with less manual work. It is built for users who want a simple way to run a bot on Windows and keep it active while they manage their market strategy.

It can help you:

- Place buy and sell orders around a target price
- Keep quotes active across a market
- Manage order size and spread settings
- Run on Windows without a full setup process
- Save time compared with placing orders by hand
